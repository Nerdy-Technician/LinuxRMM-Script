# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/Nerdy-Technician/LinuxRMM-Script/security/advisories/new)

Include what you found, where (file or URL), and steps to reproduce. You'll get a response as soon as possible, and credit once a fix is out if you'd like it.

## Supported versions

Only the latest version on the `main` branch (and the latest release, where there are releases) receives security fixes.
